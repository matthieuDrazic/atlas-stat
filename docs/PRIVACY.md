# Confidentialité
Aucun compte, traceur, cookie publicitaire ou collecte serveur par Atlas. Favoris, recherches récentes, apparence et cache restent dans le navigateur. Les imports sont temporaires et locaux ; ne pas importer de données personnelles. Les requêtes externes applicatives concernent l’INSEE, Eurostat, la Banque mondiale et, lors d’une recherche de commune, geo.api.gouv.fr. Elles sont liées à la consultation demandée. Les copies locales évitent une requête distante quand elles couvrent la recherche. Le producteur reçoit des métadonnées réseau usuelles (dont adresse IP) et les paramètres publics de requête. GitHub assure l’hébergement et possède ses propres règles de journalisation.
Pour supprimer tout le stockage : effacer les données du site dans les paramètres du navigateur. « Vider le cache » ne supprime pas les favoris. Les fonctionnalités de stockage restent facultatives ; en cas de refus du stockage, la consultation reste possible.

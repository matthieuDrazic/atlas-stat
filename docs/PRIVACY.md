# Confidentialité
Aucun compte, traceur, cookie publicitaire ou collecte serveur par Atlas. Favoris, recherches récentes, apparence et cache restent dans le navigateur. Les imports sont temporaires et locaux ; ne pas importer de données personnelles. Les seules requêtes externes applicatives sont celles vers la Banque mondiale, explicitement liées à une consultation. Le producteur reçoit des métadonnées réseau usuelles (dont adresse IP) et les paramètres publics de requête. GitHub assure l’hébergement et possède ses propres règles de journalisation.
Pour supprimer tout le stockage : effacer les données du site dans les paramètres du navigateur. « Vider le cache » ne supprime pas les favoris. Les fonctionnalités de stockage restent facultatives ; en cas de refus du stockage, la consultation reste possible.
